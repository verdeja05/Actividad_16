# Inventario PWA

Aplicación web progresiva para administrar productos de inventario. Proyecto de la Actividad 16: Gestión de versiones y liberación controlada de una PWA.

## Tecnologías
- HTML, CSS y JavaScript
- IndexedDB para guardar los productos en el dispositivo
- Service Worker con caché versionada
- Web App Manifest
- GitHub Pages para la publicación

## Ejecutar en local
```bash
python -m http.server 5500
```
Abrir http://localhost:5500

## Versiones
Se usa Versionado Semántico (MAYOR.MENOR.PARCHE). Ver [CHANGELOG.md](CHANGELOG.md).
